"The Energy Fallacy of Thread Preemption: Empirical Quantification of Context Switching Overhead"

Evaluated preemption penalties on an AMD Ryzen 5 5625U architecture by binding an identical 100M bitwise computation workload to Core 0 across two deterministic regimes: contiguous single-thread execution versus 20,000 synchronized context switches.

Execution Slowdown 7.49x 14.75 s vs. 110.50 s
Cumulative Energy Surge +635.9% 55.96 J vs. 411.86 J
Instantaneous Power ~3.76 W Flat thermal profile
Key Finding: Proved that thread preemption overhead manifests primarily as cumulative energy waste rather than elevated instantaneous thermal dissipation.

async def hybrid_retrieval(query: str, top_k: int = 5):
    cache_key = hashlib.sha256(query.encode()).hexdigest()
    
    # 1. Fast Redis cache check to cut compute by 42%
    if cached := await redis_client.get(cache_key):
        return json.loads(cached)

    # 2. Concurrently execute dense & sparse scoring
    dense_task = asyncio.create_task(chroma_store.query_embedding(query, k=top_k*2))
    sparse_task = asyncio.create_task(bm25_index.score(query, k=top_k*2))
    dense_results, sparse_results = await asyncio.gather(dense_task, sparse_task)

    # 3. Reciprocal Rank Fusion (RRF)
    fused_scores = reciprocal_rank_fusion(dense_results, sparse_results, k=60)
    top_docs = sorted(fused_scores.items(), key=lambda x: x[1], reverse=True)[:top_k]

    await redis_client.set(cache_key, json.dumps(top_docs), ex=3600)
    return top_docs
